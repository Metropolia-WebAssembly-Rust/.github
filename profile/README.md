# WebAssembly with Rust

Welcome to the **Metropolia-WebAssembly-Rust** organization!

This organization hosts the assignments and course material for the
**WebAssembly with Rust** course at
[Metropolia University of Applied Sciences](https://www.metropolia.fi/en),
taught by **Jukka Paasonen**.

## About the course

The course introduces [WebAssembly](https://webassembly.org/) (Wasm) and shows
how to build fast, portable and safe modules with the
[Rust](https://www.rust-lang.org/) programming language. Topics include:

- Rust basics for WebAssembly development
- Compiling Rust to WebAssembly (`wasm32` targets, `wasm-pack`, `wasm-bindgen`)
- Running WebAssembly in the browser and outside it (e.g. WASI runtimes)
- Interoperating between JavaScript and Rust

## Assignments

Each assignment is its own repository in this organization. Students submit
their work through the repositories created for them via GitHub Classroom or
as instructed in the course.
